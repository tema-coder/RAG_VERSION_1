# ЭТАП 6: PDF без текстового слоя → HTTP 422 (ГОТОВ К ВЫПОЛНЕНИЮ)

Этап 5 принят полностью. Child-Parent retrieval работает корректно.
Теперь исправляем статус-код для PDF без текстового слоя: было 400, должно быть 422.

## Задача
Вынести ошибку отсутствия текстового слоя в отдельный подтип и маппить её на HTTP 422.

## Что сделать
1. core/interfaces.py:
   - Создать новый класс исключения OcrDisabledError(DocumentParseError):
     """PDF без текстового слоя не поддерживается, OCR отключён."""
   
2. parsers/dedoc_parser.py:
   - В методе parse(), при проверке результата dedoc для PDF:
     Если markdown пустой И расширение == ".pdf" → raise OcrDisabledError(filename=path.name)
   - Убедиться, что сообщение ошибки точно соответствует ТЗ: "PDF без текстового слоя не поддерживается, OCR отключён".

3. api/routes.py:
   - В обработчике POST /api/parse добавить except OcrDisabledError as exc:
     raise _error(422, exc.message, "ocr_disabled")
   - Обновить responses={...} эндпоинта: добавить 422 с моделью ErrorResponse.

4. Тесты (tests/test_parsers.py или test_api.py):
   - Добавить тест test_pdf_no_text_layer_returns_422:
     * Использовать синтетический PDF-фикстур без текстового слоя (или мокировать DedocManager.parse).
     * Проверить status_code == 422.
     * Проверить detail содержит "OCR отключён".
     * Проверить X-Error-Type header == "ocr_disabled".
   - Убедиться, что существующие тесты на PDF с текстовым слоем не сломались.

5. .env.example и README (черновик):
   - В .env.example добавить комментарий: # PDF без текстового слоя → 422 (OCR отключён)
   - В README (раздел форматов) уточнить: ".pdf — только текстовый слой; сканы → 422"

## Критерии приёмки Этапа 6
- pytest rag_parser/tests/test_parsers.py::test_pdf_no_text_layer_returns_422 -q → зелёный.
- При парсинге реального скана (если есть в input/) → статус 422, не 400.
- Все остальные тесты PDF (с текстовым слоем) проходят без изменений.
- Никаких других изменений в коде. Только новый exception и его обработка.

Выполни Этап 6. После завершения сообщи:
1. Результат прогона теста на 422 для PDF без слоя.
2. Общий прогон: 324 passed должно сохраниться (+1 новый тест = 325).
3. Статус-код 422 подтверждён для скана (если есть тестовый файл).

Не коммить промежуточные изменения. Жди подтверждения перед Этапом 7 (scripts/process_input_folder.py).
