# ЭТАП 5: Child-Parent Retrieval (expand_to_parents + эндпоинт) (ГОТОВ К ВЫПОЛНЕНИЮ)

Этап 4 принят полностью. parent_id и chunk_order работают стабильно и детерминированно.
Теперь реализуем логику группировки чанков при поиске и соответствующий API-эндпоинт.

## Задача
Создать чистую функцию expand_to_parents() и GET-эндпоинт /api/parse/{document_id}/parents?index=N.

## Что сделать
1. core/retrieval.py (НОВЫЙ файл):
   - Реализовать чистую функцию:
     def expand_to_parents(chunks: List[Chunk], hit_index: int) -> List[Chunk]:
       """
       Если chunks[hit_index].parent_id is None → вернуть [chunks[hit_index]].
       Иначе найти все чанки с тем же parent_id, отсортировать по chunk_order, вернуть список.
       """
   - Функция НЕ должна зависеть от FastAPI, Pydantic или document_store. Только dataclasses Chunk.
   - Покрыть unit-тестами: 
     * test_expand_orphan_returns_single
     * test_expand_group_returns_sorted_by_order
     * test_expand_preserves_table_and_text_chunks_in_group

2. api/routes.py:
   - Добавить эндпоинт:
     @router.get("/parse/{document_id}/parents", response_model=List[ChunkResponse])
     async def get_parent_group(document_id: str, index: int = Query(..., ge=0))
   - Логика:
     * Получить документ из document_store по document_id.
     * Найти chunks[hit_index]. Проверить bounds → 404 если вне диапазона.
     * Вызвать expand_to_parents(chunks, hit_index).
     * Вернуть результат.
   - Обработка ошибок: 
     * document_id не найден → 404
     * index >= len(chunks) → 400 "index out of range"

3. Тесты (tests/test_retrieval.py):
   - test_expand_function_unit: моковые чанки, проверка логики без API.
   - test_api_endpoint_integration: 
     * Создать тестовый документ через POST /api/parse.
     * Вызвать GET /api/parse/{id}/parents?index=N для чанка с parent_id.
     * Проверить, что вернулись ВСЕ чанки группы, отсортированные по chunk_order.
     * Вызвать для orphan-чанка → проверить, что вернулся только он.
   - test_api_error_cases: неверный document_id, index за пределами.

## Критерии приёмки Этапа 5
- pytest rag_parser/tests/test_retrieval.py -q → зелёный.
- expand_to_parents() работает корректно на моковых данных (orphan и группа).
- Эндпоинт возвращает правильную группу чанков для реального документа gost_report.docx.
- Для orphan-чанка эндпоинт возвращает массив из одного элемента.
- Ошибки (404, 400) обрабатываются корректно.
- Никаких других изменений в коде. Только retrieval.py и routes.py + тесты.
