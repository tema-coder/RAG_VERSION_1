# Верхнеуровневые зависимости rag_parser.
#
# Версии здесь — МЯГКИЕ диапазоны. Точное рабочее окружение зафиксировано
# в ../constraints.txt и устанавливается ВМЕСТЕ с этим файлом:
#
#     pip install --no-deps "dedoc==2.8"
#     pip install -r rag_parser/requirements.txt -c constraints.txt
#
# Порядок важен: dedoc ставится ПЕРВЫМ и БЕЗ зависимостей, остальное — вторым.
#
# Почему такой порядок: dedoc 2.8 — пакет 2023 года с жёсткими пинами
# (starlette<=0.27.0, scipy<=1.11.2, python-docx==0.8.11), несовместимые
# с современными FastAPI/Streamlit. Если поставить его обычным резолвером,
# pip завершается ResolutionImpossible. Мы импортируем только DedocManager;
# затрагиваемые его пинами модули (dedoc.api, OCR-ридеры) сервис не грузит.
# Подробности — в constraints.txt и README, раздел «Отклонения от ТЗ».
