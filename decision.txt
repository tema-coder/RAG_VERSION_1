Решение по зависимостям (для README)
Вместо жесткого requirements.txt используйте подход с constraints:
Создайте файл constraints.txt через pip freeze > constraints.txt.
В requirements.txt оставьте только верхнеуровневые пакеты без версий (или с мягкими диапазонами):
dedoc>=2.8
fastapi>=0.104
uvicorn[standard]>=0.23
chonkie>=1.3
streamlit>=1.38
pytest>=8.3
# ... остальные основные зависимости
В README укажите команду установки именно через constraints:
pip install -r requirements.txt -c constraints.txt
Это стандартная практика для проектов со сложными транзитивными зависимостями. Вы зафиксируете рабочее состояние, а не будете гнаться за идеальным pin'ом каждой библиотеки.
